# 峰谷罗盘 (Peak–Valley Compass)

把不同批次的 chromatogram 对齐到参考运行，同时**保留真实保留时间漂移**：自动
warping 不会被“悄悄排序修正”，任何破坏单调性的锚点都会在保存前以**最小拒绝
集合**形式退回给研究员。原始曲线永不改写，所有派生曲线都能追溯到原始采样点与
映射版本。

## 准备

```bash
go build ./...
```

## 演示

```bash
go test ./... -count=1
go run ./cmd/server --addr 127.0.0.1:5238
```

打开 <http://127.0.0.1:5238>，页面标题为 **峰谷罗盘**。首次启动会在项目数据
目录 `./.peakcompass/compass.db`（SQLite）自动播种 4 条确定性运行：

- `run-ref`：参考运行，含一个**三点平顶峰**(t≈4.5) 与两个**等 prominence 并列
  候选峰**(t≈8.0 / 9.2)；
- `run-shift`：同一仪器、0.1 min 采样，平滑正向漂移；
- `run-coarse`：不同仪器、**0.15 min 不等间隔采样**，负向漂移；
- `run-partial`：**缺失早峰**（只在部分运行出现的锚点）。

可用 `--data <dir>` 指定数据目录，`--no-seed` 关闭自动播种。

## 能力与对应实现

- **导入**：`POST /api/runs`（times/values + 样本、仪器元数据）；页面侧栏支持
  每行 `time,signal` 的 CSV 粘贴导入。原始样本以 float64 BLOB 存储，永不更新。
- **候选峰检测**：`internal/detect`，保留原曲线、检测参数(`DetParams`)与峰边界
  (`leftIdx/apexIdx/rightIdx`)。平顶按等值平台分组；prominence 向两侧求基底；
  梯形面积；等 prominence 候选打并列标记；min-distance 过滤保留被拒原因。
- **峰身份**：稳定字符串 ID，**不依赖数组下标**；重检测经
  `peaksets.Migrate/ApplyMigration` 做确定性匹配（峰位时间→面积→序号），报告
  迁移 / 消失 / 新增。合并、平顶拆分、忽略 / 恢复都生成**可撤销新版本**，历史
  行（含 merged/split 来源峰）完整保留；冻结后需 branch 才能再编辑。
- **锚点与单调映射**：`internal/warp.Build`。
  - 精确重复 `(x,y)` 折叠；同 x 不同 y 判为 vertical；
  - 交叉用**加权最长递增子序列**求最小拒绝集（manual 权重高，平局确定性打破），
    **绝不用全局排序掩盖**；校验/保存接口返回每个被拒锚点及对立方；
  - `Eval`/`InverseEval` 为分段线性（端点钳制，避免外推）。
- **局部重算与锁区段**：`AffectedRange` 给出移动某锚点仅影响的相邻两区段；
  `CheckLocks` 使与锁区段相交的调整被 409 拒绝，**锁区段逐点一致**。
- **自动建议**：`SuggestProposals` 每峰保留多个候选，说明形状（对称/前伸/拖尾/
  平顶）、面积比与邻峰顺序，近似并列显式标 ambiguous。默认锚点用保序 DP
  (`MatchPeaks`) 对齐，缺峰不错配。
- **血缘**：每个对齐点 `LineagePoint` 记录 `srcIdx/srcTime`（原始采样）、是否
  插值、`mappingId/mapVer`。
- **批次共识**：`internal/consensus` 仅接受**已冻结**映射；逆映射到参考轴后按
  时间质心聚类；每个峰族列出支持运行与缺失运行；面积归一化规则
  (`total_area|median|none`) **固定在版本中**。
- **版本与并发**：峰集 / 映射 / 共识均版本化；提交带 `baseVersion`，旧版本并发
  提交返回 `409 stale_version`。冻结映射之后可用 `baseVersion=-1` 开新系列。
- **恢复**：全部状态在 SQLite；重启后草案与冻结结果都可恢复，空库才播种。

## 页面

- 原始 / 对齐曲线叠加（含每点血缘元信息）；
- 候选峰表（边界、形状、并列、状态）与合并/拆分/忽略/恢复/撤销/冻结；
- 锚点图可鼠标拖动（触发局部重算与锁检查）、双击划定锁区间、残差曲线；
- 峰族共识表（支持/缺失、原始与归一化面积）；
- 版本比较（映射差异 diff、峰集/映射/共识历史）。
